# Expense Tracker — TDD

Studentët: Besjana Kurtaj, Altin Brahimaj

Aplikacion për regjistrimin dhe menaxhimin e shpenzimeve personale. Qëllimi është të regjistrohen shpenzimet, të llogaritet totali dhe të filtrohen shpenzimet sipas kategorisë.

Teknologjitë: C#, .NET 8, xUnit, dotnet CLI. Metodologjia: Test Driven Development (Red–Green–Refactor).

## Ekzekutimi
Kërkohet .NET 8 SDK. Nga rrënja e projektit: `dotnet test`.

**Shënim:** Detyra origjinale përmend JUnit 5 (Java). Ky version përdor xUnit (C#); konfirmoni pranimin me profesoreshën.
